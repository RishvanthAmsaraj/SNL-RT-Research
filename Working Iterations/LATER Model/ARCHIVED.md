# LATER Model — Archived

**Status:** archived (September 2026).

The LATER (Linear Approach to Threshold with Ergodic Rate) reciprobit model was explored as a saccade-native complement to the single-boundary shifted Wald. See the technical breakdown (`../../Current Pipeline/Documents/SNL_RT_Research_Technical_Breakdown.md`, Section 8) and `Code/LATER_analysis.py`.

**Why it was archived:** LATER was a tie against the Wald on hands, and its rate/threshold parameters are not comparable to the Wald's drift/boundary/non-decision-time, so it offered no compelling benefit as a drop-in replacement or a complement. The project has standardized on the **single-boundary shifted Wald** as the sole production model.

- `Code/` — the LATER fitting script and its fit table.
